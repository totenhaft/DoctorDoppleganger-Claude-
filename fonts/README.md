# 기본 자막 글꼴 (선택)

이 폴더에 **Pretendard** 글꼴 파일을 넣어 두면, 영상 자막의 기본 글꼴로 맑은 고딕 대신 Pretendard 를 씁니다.

1. https://github.com/orioncactus/pretendard/releases 에서 `Pretendard-1.3.9.zip` 을 내려받습니다.
2. 압축을 풀고 `public/static/` 폴더 안의 아래 세 파일을 이 `fonts/` 폴더로 복사합니다.
   - `Pretendard-Medium.otf`
   - `Pretendard-Bold.otf`
   - `Pretendard-ExtraBold.otf`
3. 프로그램을 다시 켭니다.

Pretendard 는 SIL 오픈 폰트 라이선스라 영상에 자유롭게 쓸 수 있습니다.
글꼴 파일은 GitHub 에 올라가지 않도록 `.gitignore` 에 들어 있습니다.
